## 路线与 TinyOS 对照

按书的顺序推进，每章先讲清"本章的输入、输出、模块关系、运行路径"，再动手。

| 章 | 主题 | 与 TinyOS 的关系 |
| --- | --- | --- |
| ch1 | 应用程序与基本执行环境 | TinyOS 有入口/栈；补齐 QEMU 预加载、固件交接与基本运行时的模型 |
| ch2 | 批处理系统 | 特权切换、应用装载与退出；ELF/独立地址空间还要继续到 ch4 对照 |
| ch3 | 多道程序与分时多任务 | TinyOS 已有 sched/timer/yield，对照 rCore 的写法 |
| ch4 | 地址空间 | TinyOS 自己实现了 Sv39；这章讲清 satp/映射/跳板与"地址空间"这个抽象 |
| ch5 | 进程及进程管理 | TinyOS 缺：进程概念、fork/exec/wait |
| ch6 | 文件系统 | TinyOS 缺：块设备、inode、easy-fs |
| ch7 | 进程间通信 | TinyOS 缺：管道 |
| ch8 | 并发 | TinyOS 缺：线程与同步原语 |
| ch9 | 设备管理 | 串口与 virtio，形成完整设备路径 |

不按 TinyOS 已有代码跳章或赶进度；先完整理解每章路径，再继续。具体完成点见 ROADMAP.md。
